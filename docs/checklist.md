# make.fun Bounty Submission Checklist

Before submitting your entry, verify each of the following requirements:

## Repository Structure & Metadata
- [ ] **README.md** is at the repo root and named exactly `README.md`.
- [ ] **README.md** file size is under 2MB.
- [ ] **README.md** includes the referral code.
- [ ] **README.md** contains the three `make.fun` badge lines intact.
- [ ] **No .github/README.md** exists (it must be at the root).
- [ ] **Repository is public** and owned by the linked GitHub account.
- [ ] **Repository was created** after the competition opening date.
- [ ] **OSI-approved license** is present in the repository.
- [ ] **GitHub "About" section** is set to a `make.fun` website.
- [ ] **GitHub Topics** include `makefun`.

## Media Requirements
- [ ] **screenshot.png** (or .jpg/.webp) is at the root.
- [ ] **Screenshot file size** is under 8MB.
- [ ] **Screenshot resolution** is under 16 million pixels total.
- [ ] **Top of screenshot** clearly shows the repo name and the start of the README.

## Technical & Process Requirements
- [ ] **Transcripts** from a recorded harness are included with usage details.
- [ ] **Record command** used the format: `record --harness=<harness> --provider=<provider> --model=<model> --effort=<effort>`.
- [ ] **Entrypoint** was written or edited across at least 2 assistant messages.

## Submission Limits & Deadlines
- [ ] **Daily limit:** Fewer than 5 submissions have been made this UTC day.
- [ ] **Total limit:** Fewer than 10 submissions have been made in total for this bounty.
- [ ] **Deadline:** Final submission will be received before the deadline.
